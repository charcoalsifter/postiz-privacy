What to Include in Your Message

To help us respond as quickly as possible, please include the following relevant information in your message:

For Privacy Questions

  • A clear description of your question or concern
  • Relevant context about how you use the application

For Data Deletion Requests

  • Your name or display name associated with the account
  • The Facebook Page name(s) or ID(s) connected (if applicable)
  • Subject line: "Data Deletion Request – Postiz Social Manager"

For Facebook Integration Issues

  • A description of the issue you are experiencing
  • The Facebook Page name or ID (if applicable)
  • Any error messages you received
