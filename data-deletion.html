ℹ️ Your Right to Data Deletion

You have the right to request deletion of your personal data processed by Postiz Social Manager. This page explains exactly how to do that.

📧
Option 1

Request Deletion by Email

To request that your personal data be deleted from Postiz Social Manager, send an email to our data contact address.

📧 Data Deletion Email

Send your deletion request to:

info@montaguecommoners.org

What to Include in Your Request

  • Your name or display name associated with the account
  • The Facebook Page name(s) or ID(s) connected to the application (if applicable)
  • A brief description of the data you want deleted
  • Your preferred contact method for confirmation

What Happens After You Request

  1. Request Received

    We will acknowledge your deletion request by email within a reasonable timeframe.

  2. Verification

    We may ask you to verify your identity to ensure the request is legitimate and to locate the correct data.

  3. Data Deletion

    We will delete or de-identify your personal data from our active systems. Certain technical logs may be retained for a limited period for security purposes.

  4. Confirmation

    We will send you a confirmation once the deletion has been completed.

🔗
Option 2

Revoke Access Through Facebook

You can revoke Postiz Social Manager's access to your Facebook account at any time directly through Meta's settings. This immediately prevents the application from making further API calls to Facebook on your behalf.

  1. Open Facebook Settings

    Go to Facebook Settings → Apps and Websites or navigate there from your Facebook account settings.

  2. Find the Application

    Locate Postiz Social Manager in the list of connected apps.

  3. Remove the App

    Click Remove or View and Edit then select Remove. Confirm the removal.

  4. Confirm Revocation

    The application will immediately lose access to your Facebook account. You may also request deletion of application-stored data by emailing us as described in Option 1.

⚠️ Note

Revoking access through Meta prevents further API access but does not automatically delete data already stored within the Postiz Social Manager application (such as scheduled posts or connected Page records). To request deletion of that data, please also submit an email deletion request.

⚙️
For Developers

Meta Data Deletion Callback (Developers)

Meta may require a Data Deletion Callback URL as part of Facebook Login configuration. This is a server-side endpoint that Meta calls when a user removes your app from their Facebook settings.

⚠️ Important Note

This static informational page is not a valid Meta Data Deletion Callback endpoint. A valid callback endpoint must be a dynamic server-side URL that can receive and process HTTP POST requests from Meta and return a valid JSON response with a confirmation code.

If your Postiz deployment requires a Meta Data Deletion Callback URL, you will need to implement a server-side endpoint within your Postiz backend or a separate lightweight API. The endpoint must:

  • Accept HTTP POST requests from Meta
  • Parse the signed_request parameter
  • Process the deletion request for the identified user
  • Return a JSON response with a url (status page) and confirmation_code

For manual data deletion requests, use the email contact method described above. For questions about implementing a Meta Data Deletion Callback in your Postiz deployment, contact us at gamefloper11@gmail.com.
